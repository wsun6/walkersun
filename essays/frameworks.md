*A web page I built using Bootstrap 5 based on the Arrowhead Games website*

Bootstrap 5 offer several advantages that make web development faster and more efficient compared to using raw HTML and CSS. Learning Bootstrap was annoying and frustrating at first, but that comes with learning anything new. Through repetition and practice, I got more familiar with Bootstrap and was able to find more success.
I found some aspects of Bootstrap more convenient in some circumstances through the its built in systems and classes. The navbars, buttons, and hamburger menus were a lot easier to make than if I were to make everything using CSS media queries. I haven't had too much experience, but I imagine that if I were to consistently work on the same Bootstrap project, it would be easier to understand Bootstrap code. It was easier to edit and read than raw HTML when I was debugging or trying to implement something new.

However, raw HTML and CSS still have advantages, as you have more raw control over the website. If someone were very comfortable using HTML and CSS, they might find it better than Bootstrap as they would be able to dictate more of the web page.Overall, I believe Bootstrap 5 is worth learning because it improves development efficiency, responsiveness, consistency, and maintainability. While it does not replace the need to understand HTML and CSS, it provides useful tools that make building larger and more complex websites easier. It is important to learn a little bit of everything such that you have a better understanding of all aspects.
