Software engineering is a very broad subject and encapsulates a lot of different topics. Engineering is about solving problems, and software engineering would be software problems. Therefore, I am interested in learning about what I would need to know in order to solve any problems that I would encounter. I hope to be able to use the skills that I develop to work on an important project, whatever that might be. This is something that I haven't put a great amount of thought into, as I am mainly focused on my current studies, but I am keen on seeing the applications of software engineering in robotics or other kinds of machinery. 

I think that it is important to learn some level of programming, no matter what field you're studying. Everything is linked to the digital network now, and being able to have even a slight comprehension of how computers work goes a long way. The more technical the field, the more software engineering you should know, especially if you are going to be involved with software. The problem solving techniques as well as the process is important to familiarize yourself with, as it goes farther than getting a program to spit out the text that you want. It can apply to all sorts of problems that people encounter daily, as well as other classes in school.

Software engineering isn't something that I can easily pin down and describe, but it is still something that I am interested in learning about. As a lot of knowledge about programming can be attained from using AI, there are still aspects that aren't easily replicated. Identifying problems and coming up with the blueprint for a solution is something that a person will need to do. The skills to do this take time and experience to develop, which is what I hope to be doing in the future.
